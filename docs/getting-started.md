# Getting Started

## How to Use This Website

1. Select a topic from the navigation menu.
2. Open Concept.md to understand the topic.
3. Open Questions.md to practice interview questions.
4. Click a question to read its answer.
5. Use the search bar to find a topic.

Spring Boot → Spring Security → Microservices →
System Design → Coding Interview.
